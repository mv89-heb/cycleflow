# MyCycle Pro (CycleFlow)

אפליקציית PWA פרטית למעקב מחזור וסת, טהרת המשפחה, וחלון פוריות. כל הנתונים נשמרים **מקומית בלבד** בדפדפן (localStorage) — שום מידע אישי לא נשלח לשרת.

> ⚠️ **הבהרה**: האפליקציה מסייעת בארגון מידע בלבד. היא **אינה פוסקת הלכה** ו**אינה תחליף לייעוץ רפואי**. בכל שאלה יש לפנות לרב/יועצת הלכה מוסמכת או לרופא/ה.

## ארכיטקטורה

```
cycleflow-main/
├── app.py                  # שרת Flask דק - מגיש SPA + Service Worker
├── requirements.txt        # תלויות Python
├── render.yaml             # קונפיגורציית פריסה ל-Render
├── package.json            # הרצת בדיקות (npm test)
├── templates/
│   └── index.html          # מבנה ה-SPA (RTL, עברית)
├── static/
│   ├── css/main.css        # עיצוב (כולל ערכת נושא כהה/בהירה)
│   ├── js/app.js           # כל הלוגיקה (state, halacha, fertility, UI)
│   ├── js/backup-integrity.js # פורמט גיבוי מוצפן versioned וייבוא transactional
│   ├── js/hardening.js     # ולידציית state והקשחת צד לקוח
│   ├── sw.js               # Service Worker - תמיכה offline
│   └── manifest.json       # PWA manifest (התקנה למסך הבית)
└── tests/
    ├── logic.test.js          # בדיקות יחידה ללוגיקת הליבה וה-UI
    ├── data-integrity.test.js # בדיקות כרונולוגיה וכתמים
    ├── pwa.test.js            # בדיקות נכסי Offline
    ├── state-recovery.test.js # בדיקות שמירת נתונים ושחזור
    └── backup-integrity.test.js # בדיקות הצפנה וייבוא transactional
```

**עקרון מרכזי**: השרת (Flask) הוא stateless ומגיש קבצים סטטיים בלבד. נתוני המעקב נשמרים בצד הלקוח ואינם נשלחים לשרת. עם זאת, גופנים, אייקונים וגרף נטענים כיום מספקי CDN חיצוניים; ספקים אלה עשויים לקבל מטא-נתוני חיבור כגון כתובת IP וסוג דפדפן. לא נשלחים אליהם נתוני המחזור עצמם. במצב Offline, גופנים, אייקונים וגרפים חיצוניים עשויים להיות חסרים.

### מודולים בצד הלקוח

| מודול | תפקיד |
|-------|--------|
| `Utils` | פעולות תאריך (עמידות בשנים מעוברות ומעברי חודש/שנה) |
| `SecurityService` | גיבוב PIN (SHA-256) |
| `CryptoService` | הצפנת גיבויים (AES-256-GCM + PBKDF2) |
| `StorageService` | טעינה/שמירה/ייצוא/יבוא ל-localStorage |
| `StateManager` | ניהול מצב מרכזי עם מנגנון subscribe/notify |
| `HalachaLogic` | מעקב סטטוס יומי, כולל סימון טבילה מפורש (אינו פוסק הלכה) |
| `FertilityLogic` | הערכת ביוץ, חלון פוריות ווסת הבאה (שיטת לוח שנה) |
| `Calculator` | מחשבון פונקציונלי להסוואה |
| `UI` | רינדור וטיפול באירועים |

## הרצה מקומית

```bash
pip install -r requirements.txt
python app.py                    # http://localhost:5000
```

לפיתוח עם debug:
```bash
FLASK_DEBUG=true python app.py
```

**בייצור** יש להגדיר `SECRET_KEY` קבוע:
```bash

```

## גיבוי ושחזור

- גיבויים חדשים נשמרים בפורמט versioned מסוג `CFBK v2`.
- ההצפנה היא AES-256-GCM עם מפתח שמופק באמצעות PBKDF2-SHA256 ו־600,000 איטרציות.
- יצירת גיבוי חדש מחייבת סיסמה באורך 10 תווים לפחות; פתיחת גיבויים ישנים נשארת נתמכת.
- גיבויים מהפורמט הישן עם 100,000 איטרציות ממשיכים להיות נתמכים לצורך תאימות לאחור.
- קובץ גיבוי עובר validation לפני החלפת ה־state הקיים.
- import כושל (קובץ פגום, סיסמה שגויה או state לא תקין) אינו אמור לשנות את הנתונים הקיימים.
- גודל קובץ גיבוי מוגבל ל־5MB.

## פרטיות ואבטחה

- **אחסון מקומי בלבד** — אין שרת נתונים.
- **נעילת מסך PIN** — גיבוב SHA-256, לא נשמר בטקסט גלוי. זו שכבת פרטיות בסיסית בלבד, לא הצפנת נתונים ולא הגנה מפני מי שיש לו גישה טכנית לדפדפן.
- **גיבוי מוצפן** — AES-256-GCM עם מפתח נגזר מסיסמה.
- **מצב דיסקרטי** — טשטוש מסך בלחיצה.
- **מחשבון הסוואה** — מחשבון עובד; יציאה בלחיצה ארוכה על AC.
- **כותרות אבטחה** — X-Frame-Options, nosniff, Referrer-Policy ו־Content-Security-Policy.
- **State validation** — בדיקות מבנה וערכים לפני שמירת state.
- **Recovery guard** — state לא תקין נשמר בעותק מקומי נפרד, ושמירות רגילות נחסמות עד שחזור או איפוס מפורש.
- **סימון טבילה** — הסטטוס לאחר ליל הטבילה נשען על דיווח מפורש ולא על הנחה שהטבילה בוצעה.

### מגבלות פרטיות
הנתונים החיים נשמרים ב־localStorage ואינם מוצפנים במנוחה. מי שיש לו גישה למכשיר ולדפדפן עשוי לגשת אליהם דרך כלי הפיתוח או קוד שרץ באותו origin. ההצפנה מגינה על קובץ הגיבוי המיוצא בלבד. נעילת ה-PIN אינה תחליף להצפנת המידע. ספקי ה-CDN מקבלים מטא-נתוני חיבור בעת טעינת משאבים חיצוניים.

## מגבלות פריסה ב-Render Free

ה־Blueprint מוגדר במפורש ל־`plan: free` כדי למנוע חיוב לא מכוון. שירות Web חינמי ב־Render עשוי להיכנס למצב שינה לאחר 15 דקות ללא תעבורה ולהתעורר באיטיות בבקשה הבאה. לכן הוא מתאים לשימוש אישי/תחביבי, אך אינו מספק זמינות רציפה של שירות Production. ה־PWA שכבר הותקן יכול להמשיך לפעול Offline לאחר טעינה ראשונה, בכפוף למגבלות נכסים חיצוניים.

## לוגיקת נתונים

- דיווחי `veset` ממוינים כרונולוגית לפני חישובים.
- רשומות `spotting` אינן נספרות כווסת לצורך חישוב אורך מחזור.
- הזנת היסטוריה אינה תלויה בסדר שבו הרשומות הוזנו.
- חישובי פוריות והווסת האחרונה נשענים על רשומות וסת (`veset`) תקינות בלבד.
- שדה `isSunset` נשמר ומוצג, אך אינו משולב כרגע בחישובי `HalachaLogic`; המנוע משתמש בתאריכים אזרחיים בלבד.

> ⚠️ **הלכה ורפואה**: לוגיקת ההלכה היא מודל ארגוני מפושט ואינה תחליף לפסיקה. כרגע אין חישוב תאריך עברי או התאמת יום לפי שקיעה ומיקום; לכן אין להסתמך על תוצאות הסטטוס לצורך החלטה הלכתית. גם חיזוי פוריות בשיטת לוח השנה מוגבל בדיוקו, במיוחד במחזורים לא סדירים.

## CI/CD

GitHub Actions מריץ:

1. JavaScript — התקנת תלויות והרצת `npm test` על Node 24.
2. Python — התקנת תלויות, `pip-audit` לסריקת חולשות והרצת Flask smoke test על Python 3.12.

ה־workflow מוגדר לרוץ על pushes ל־`main` ול־`hardening-2026-08`, וכן על pull requests ל־`main`.
