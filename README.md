# MyCycle Pro (CycleFlow)

אפליקציית PWA פרטית למעקב מחזור וסת, טהרת המשפחה, וחלון פוריות. כל הנתונים נשמרים **מקומית בלבד** בדפדפן (localStorage) — שום מידע אישי לא נשלח לשרת.

> ⚠️ **הבהרה**: האפליקציה מסייעת בארגון מידע בלבד. היא **אינה פוסקת הלכה** ו**אינה תחליף לייעוץ רפואי**. בכל שאלה יש לפנות לרב/יועצת הלכה מוסמכת או לרופא/ה.

## ארכיטקטורה

```
cycleflow-main/
├── app.py                  # שרת Flask דק - מגיש SPA + Service Worker
├── requirements.txt        # תלויות Python
├── render.yaml             # קונפיגורציית פריסה ל-Render
├── package.json            # הרצת בדיקות (npm test)
├── templates/
│   └── index.html          # מבנה ה-SPA (RTL, עברית)
├── static/
│   ├── css/main.css        # עיצוב (כולל ערכת נושא כהה/בהירה)
│   ├── js/app.js           # כל הלוגיקה (state, halacha, fertility, UI)
│   ├── sw.js               # Service Worker - תמיכה offline
│   └── manifest.json       # PWA manifest (התקנה למסך הבית)
└── tests/
    └── logic.test.js       # בדיקות יחידה ללוגיקת הליבה
```

**עקרון מרכזי**: השרת (Flask) הוא stateless ומגיש קבצים סטטיים בלבד. כל הלוגיקה והנתונים חיים בצד הלקוח. זה נותן פרטיות מקסימלית — אין בסיס נתונים, אין חשבונות, אין שליחת מידע.

### מודולים בצד הלקוח (`app.js`)

| מודול | תפקיד |
|-------|--------|
| `Utils` | פעולות תאריך (עמידות בשנים מעוברות ומעברי חודש/שנה) |
| `SecurityService` | גיבוב PIN (SHA-256) |
| `CryptoService` | הצפנת גיבויים אמיתית (AES-256-GCM + PBKDF2) |
| `StorageService` | טעינה/שמירה/ייצוא/יבוא ל-localStorage |
| `StateManager` | ניהול מצב מרכזי עם מנגנון subscribe/notify |
| `HalachaLogic` | חישוב סטטוס יומי (נידה/הפסק/נקיים/טבילה/עונה בינונית) |
| `FertilityLogic` | הערכת ביוץ, חלון פוריות ווסת הבאה (שיטת לוח שנה) |
| `Calculator` | מחשבון פונקציונלי להסוואה |
| `UI` | רינדור וטיפול באירועים |

## הרצה מקומית

```bash
pip install -r requirements.txt
python app.py                    # http://localhost:5000
```

לפיתוח עם debug:
```bash
FLASK_DEBUG=true python app.py
```

**בייצור** יש להגדיר `SECRET_KEY` קבוע:
```bash
export SECRET_KEY="<מפתח-אקראי-חזק>"
gunicorn app:app
```

## בדיקות

```bash
npm install       # מתקין jsdom
npm test          # מריץ 28 בדיקות ליבה
```

## פרטיות ואבטחה

- **אחסון מקומי בלבד** — אין שרת נתונים.
- **נעילת PIN** — גיבוב SHA-256, לא נשמר בטקסט גלוי.
- **גיבוי מוצפן** — AES-256-GCM עם מפתח נגזר מסיסמה (PBKDF2, 100K איטרציות). ללא הסיסמה אי אפשר לשחזר.
- **מצב דיסקרטי** — טשטוש מסך בלחיצה.
- **מחשבון הסוואה** — מחשבון עובד; יציאה בלחיצה ארוכה על AC.
- **כותרות אבטחה** — X-Frame-Options, nosniff, Referrer-Policy (OWASP).

## Changelog (v2.0 — Debug & Hardening)

### תיקוני אבטחה (Critical)
- הוחלף "גיבוי מוצפן" מדומה (Base64) בהצפנת AES-256-GCM אמיתית.
- הוסר `SECRET_KEY` קשיח מהקוד; נדרש כעת ממשתנה סביבה.
- `debug` נשלט דרך `FLASK_DEBUG` בלבד (לא דלוק בייצור).
- נוספו כותרות אבטחה (OWASP).

### תיקוני באגים
- **אובדן הערות**: הערה יומית נשמרת כעת בסגירת הפאנל ותוך כדי הקלדה (לפני כן אבדה).
- **קוד מת**: לוגיקת "עונה בינונית" הייתה בלתי-נגישה במצבים מסוימים — תוקנה.
- **ולידציה כרונולוגית**: מניעת דיווח וסת בתאריך עתידי / קודם לוסת אחרונה / כפול.
- **מחיקת רישום**: נוספה אפשרות למחוק דיווח שגוי (לפני כן רק איפוס מלא).
- **מחשבון הסוואה**: היה לא-פונקציונלי; מומש במלואו.
- **קאשינג**: נוסף cache-busting אוטומטי (mtime) לקבצי CSS/JS.

### פיצ'רים חדשים
- **מנוע פוריות**: הערכת ביוץ, חלון פוריות ווסת הבאה (לא היה קיים כלל).
- **PWA**: תמיכה offline (Service Worker) + התקנה למסך הבית (manifest).
- **ערכת נושא בהירה/כהה** עם שמירת העדפה.
- **טיפול שגיאות גלובלי** — שגיאה בודדת לא משאירה מסך ריק.
- **ערכת בדיקות** — 28 בדיקות ליבה.

### סיכונים שנותרו
- הנתונים החיים ב-localStorage נגישים דרך DevTools למי שיש גישה פיזית למכשיר פתוח (ההצפנה מגנה רק על קובץ הגיבוי המיוצא).
- לוגיקת ההלכה מפושטת (למשל: חב"ד מטופל כאשכנז; אין הבחנה מלאה בין וסת לכתם) — **טעונה אימות עם פוסק**.
- שיטת לוח השנה לפוריות מוגבלת בדיוקה, במיוחד במחזורים לא-סדירים.
