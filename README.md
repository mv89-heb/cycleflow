# MyCycle Pro (CycleFlow)

אפליקציית PWA פרטית למעקב מחזור וסת, טהרת המשפחה, וחלון פוריות. כל הנתונים נשמרים **מקומית בלבד** בדפדפן (localStorage) — שום מידע אישי לא נשלח לשרת.

> ⚠️ **הבהרה**: האפליקציה מסייעת בארגון מידע בלבד. היא **אינה פוסקת הלכה** ו**אינה תחליף לייעוץ רפואי**. בכל שאלה יש לפנות לרב/יועצת הלכה מוסמכת או לרופא/ה.

---

## ארכיטקטורה

```
cycleflow-main/
├── app.py                  # שרת Flask דק - מגיש SPA + Service Worker
├── requirements.txt        # תלויות Python
├── render.yaml             # קונפיגורציית פריסה ל-Render
├── package.json            # הרצת בדיקות (npm test)
├── templates/
│   └── index.html          # מבנה ה-SPA (RTL, עברית)
├── static/
│   ├── css/main.css        # עיצוב (כולל ערכת נושא כהה/בהירה)
│   ├── js/app.js           # כל הלוגיקה (state, halacha, fertility, UI)
│   ├── js/backup-integrity.js # פורמט גיבוי מוצפן versioned וייבוא transactional
│   ├── js/hardening.js     # ולידציית state והקשחת צד לקוח
│   ├── sw.js               # Service Worker - תמיכה offline
│   └── manifest.json       # PWA manifest (התקנה למסך הבית)
└── tests/
    ├── logic.test.js       # בדיקות יחידה ללוגיקת הליבה
    └── data-integrity.test.js # בדיקות רגרסיה לכרונולוגיית הנתונים
```

**עקרון מרכזי**: השרת (Flask) הוא stateless ומגיש קבצים סטטיים בלבד. כל הלוגיקה והנתונים חיים בצד הלקוח. זה נותן פרטיות מקסימלית — אין בסיס נתונים, אין חשבונות, אין שליחת מידע.

### מודולים בצד הלקוח

| מודול | תפקיד |
|-------|--------|
| `Utils` | פעולות תאריך (עמידות בשנים מעוברות ומעברי חודש/שנה) |
| `SecurityService` | גיבוב PIN (SHA-256) |
| `CryptoService` | הצפנת גיבויים (AES-256-GCM + PBKDF2) |
| `StorageService` | טעינה/שמירה/ייצוא/יבוא ל-localStorage |
| `StateManager` | ניהול מצב מרכזי עם מנגנון subscribe/notify |
| `HalachaLogic` | חישוב סטטוס יומי (נידה/הפסק/נקיים/טבילה/עונה בינונית) |
| `FertilityLogic` | הערכת ביוץ, חלון פוריות ווסת הבאה (שיטת לוח שנה) |
| `Calculator` | מחשבון פונקציונלי להסוואה |
| `UI` | רינדור וטיפול באירועים |

## הרצה מקומית

```bash
pip install -r requirements.txt
python app.py                    # http://localhost:5000
```

לפיתוח עם debug:
```bash
FLASK_DEBUG=true python app.py
```

**בייצור** יש להגדיר `SECRET_KEY` קבוע:
```bash
export SECRET_KEY="<מפתח-אקראי-חזק>"
gunicorn app:app
```

## בדיקות

```bash
npm install
npm test
```

ה־CI מריץ את בדיקות JavaScript ואת בדיקת ה־Flask smoke test. נכון לסבב הנוכחי, בדיקות הליבה והרגרסיה כוללות **32 בדיקות**.

## גיבוי ושחזור

- גיבויים חדשים נשמרים בפורמט versioned מסוג `CFBK v2`.
- ההצפנה היא AES-256-GCM עם מפתח שמופק באמצעות PBKDF2-SHA256 ו־600,000 איטרציות.
- גיבויים מהפורמט הישן עם 100,000 איטרציות ממשיכים להיות נתמכים לצורך תאימות לאחור.
- קובץ גיבוי עובר validation לפני החלפת ה־state הקיים.
- import כושל (קובץ פגום, סיסמה שגויה או state לא תקין) אינו אמור לשנות את הנתונים הקיימים.
- גודל קובץ גיבוי מוגבל ל־5MB.

## פרטיות ואבטחה

- **אחסון מקומי בלבד** — אין שרת נתונים.
- **נעילת PIN** — גיבוב SHA-256, לא נשמר בטקסט גלוי.
- **גיבוי מוצפן** — AES-256-GCM עם מפתח נגזר מסיסמה.
- **מצב דיסקרטי** — טשטוש מסך בלחיצה.
- **מחשבון הסוואה** — מחשבון עובד; יציאה בלחיצה ארוכה על AC.
- **כותרות אבטחה** — X-Frame-Options, nosniff, Referrer-Policy ו־Content-Security-Policy.
- **State validation** — בדיקות מבנה וערכים לפני שמירת state.

### מגבלות פרטיות
הנתונים החיים נשמרים ב־localStorage. מי שיש לו גישה למכשיר ולדפדפן כשהאפליקציה פתוחה עשוי לגשת אליהם דרך כלי הפיתוח; ההצפנה מגינה על קובץ הגיבוי המיוצא ולא על localStorage עצמו.

## לוגיקת נתונים

- דיווחי `veset` ממוינים כרונולוגית לפני חישובים.
- רשומות `spotting` אינן נספרות כווסת לצורך חישוב אורך מחזור.
- הזנת היסטוריה אינה תלויה בסדר שבו הרשומות הוזנו.
- חישובי פוריות והווסת האחרונה נשענים על רשומות וסת (`veset`) תקינות בלבד.

> ⚠️ **הלכה ורפואה**: לוגיקת ההלכה היא מודל ארגוני מפושט ואינה תחליף לפסיקה. גם חיזוי פוריות בשיטת לוח השנה מוגבל בדיוקו, במיוחד במחזורים לא סדירים.

## CI/CD

GitHub Actions מריץ:

1. JavaScript — התקנת תלויות והרצת `npm test` על Node 24.
2. Python — התקנת תלויות והרצת Flask smoke test על Python 3.12.

ה־workflow מוגדר לרוץ על pushes ל־`main` ול־`hardening-2026-08`, וכן על pull requests ל־`main`.
